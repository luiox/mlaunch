# UI 交互流程说明

## 主界面

- 左侧为分组列表，右侧为项目列表。
- 顶栏提供搜索按钮、菜单按钮、关闭按钮。
- 底栏显示状态文本（信息/警告/错误）。

## 常见交互

### 1. 分组选择

1. 点击左侧分组。
2. `active_group_id_` 更新。
3. 右侧项目列表刷新。

### 2. 项目启动

1. 双击项目或按回车。
2. 调用 `backend::LauncherBackend::Launch`。
3. 状态栏反馈执行结果。

### 3. 拖拽重排

- 分组与项目均支持拖拽重排。
- 使用阈值判定拖拽起始，避免误触。
- 鼠标释放后提交后端重排并刷新列表。

### 4. 分隔条拖拽

- 按住中间分隔条拖动调整左侧宽度。
- 通过 `GetTickCount` 节流重绘，提升流畅性。
- 松开后持久化 UI 状态。

### 5. 搜索模式

- 点击搜索按钮进入/退出搜索模式。
- 输入关键字后实时筛选右侧项目。
- `ESC` 快速退出搜索并恢复普通列表。

### 6. 右键菜单

- 分组区：新增、重命名、删除分组。
- 项目区：管理员运行、打开路径、资源管理器菜单、复制路径、增删改、移动到其它分组。
- 顶栏菜单：新建、排序、导入导出（保留入口）、设置、官网、退出。

## 窗口与状态

- `WM_SIZE` / `WM_MOVE` 会触发 `m_pm.NeedUpdate()`。
- UI 状态（窗口位置、分栏宽度等）通过防抖定时器写入 `ui_state.ini`。
